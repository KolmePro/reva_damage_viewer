Фильтры загружаются из `*.py` файлов в этой папке.

Каждый файл должен содержать список `FILTERS`.

Пример:

```python
FILTERS = [
    {
        "key": "my_filter",
        "label": "Мой фильтр",
        "group": "Моя группа",
        "default_enabled": True,
        "match_all": [
            {"field": "property1", "value": "Сила атаки"},
            {"field": "property2", "value": "Критический удар"},
        ],
    },
]
```

Поддерживаемые операторы:

- `eq` - равно
- `ne` - не равно
- `in` - значение входит в список
- `not_in` - значение не входит в список
- `startswith` - строка начинается с значения
- `not_startswith` - строка не начинается с значения

В `value` можно использовать `$player_name`, чтобы сравнивать с никнеймом игрока из интерфейса.

Необязательное поле `alternative_group` объединяет пересекающиеся фильтры:
если запись соответствует нескольким фильтрам с одинаковым значением этого поля,
достаточно включить один из них. Например, самолечение видно при включённом
входящем или исходящем лечении. Остальные фильтры продолжают действовать независимо.
