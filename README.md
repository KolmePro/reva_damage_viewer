# DamageViewer

Сделано с ♥ [Kolme.pro](https://kolme.pro)

DamageViewer разбирает логи боя из чата Revelation Online. Сохраните историю чата в игре и откройте полученный HTML-файл в программе. DamageViewer покажет события боя в таблице, построит временную шкалу и рассчитает статистику урона.

Программа помогает разобрать урон игроков и духов: кто атаковал, каким умением, по какой цели, с какими эффектами и результатом. Фильтры позволяют сосредоточиться на нужном персонаже, духе, умении или моменте боя, а объединение нескольких логов — изучить события в одной хронологии.

## Для чего пригодится

- **Проверка снаряжения.** Сравнивайте урон в боях до и после смены экипировки: отдельные удары, средние значения, разброс урона и долю критических ударов.
- **Разбор урона духов и входящего урона.** Изучайте вклад духов и атаки по танку в Башне затмения — с детализацией по атакующим и умениям.
- **Анализ гибели в PvP.** Выберите момент перед гибелью на арене или поле боя, чтобы увидеть последовательность атак, входящий урон и эффекты, записанные в логе.
- **Оценка характеристик.** Частота уклонений, блокирований и критических ударов помогает оценить, хватает ли точности и шанса крита, а подробности атак — понять, как изменения характеристик отражаются на уроне.

Статистика показывает результаты атак в выбранных записях. Для сравнения снаряжения и характеристик выбирайте бои с сопоставимыми условиями: целью, умениями и действующими эффектами.

## Возможности

- загрузка последнего боевого лога из `<папка игры>/game/chat` или выбор одного либо нескольких файлов;
- дозагрузка последнего лога к уже открытым с автоматическим удалением пересекающихся записей;
- временная шкала с отрезками боя и паузами; порог разделения боёв настраивается от 1 до 3600 секунд, по умолчанию — 30 секунд; соседние файлы без общих записей разделяются на отдельные отрезки;
- фильтрация по временному отрезку с границами `От` и `До` в удобных полях выбора времени;
- фильтрация записей одного или нескольких выбранных боёв и пауз на временной шкале;
- разбор записей о нанесенном уроне, бафах и снятии эффектов;
- таблица с временем, атакующим, целью, навыком, бафами, уроном и свойствами удара;
- фильтрация по атакующему, цели, навыку и диапазону урона с быстрым сбросом;
- настраиваемые группы фильтров через плагины из `src/filter_plugins`;
- сохранение выбранной папки игры, имени персонажа, диапазона урона, порога паузы между боями и состояния фильтров;
- сводка по урону: количество атак, сумма, минимум, максимум, среднее и медиана, а также количество и процент критических ударов, блокирований и уклонений;
- расчёт статистики по выделенным строкам или по всем отфильтрованным записям, если выделение снято;
- сборка Windows exe через PyInstaller.

## Установка

Нужен Python 3.10+.

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

## Запуск

```powershell
python src/main.pyw
```

Откройте один или несколько файлов через **Файл → Открыть логи…** (`Ctrl+O`) или кнопку на панели инструментов. Чтобы загружать самый свежий файл `chat_*.html` из подпапки `game/chat`, один раз укажите папку игры через **Настройки → Выбрать папку с игрой…**, затем нажимайте `F5`. Команда **Файл → Добавить последний лог** (`Shift+F5`) добавляет записи к уже открытым.

Обычные команды открытия заменяют ранее загруженные данные и позволяют выбрать сразу несколько файлов. Для объединения с уже открытым логом используйте команду `Добавить последний лог`. При объединении пересекающиеся строки не дублируются. Временная шкала в верхней части окна показывает длительность непрерывных отрезков боя и пауз между ними. Границы отрезков определяются только по записям с уроном: наложение и снятие эффектов не продлевает бой. Щелчок по бою или паузе добавляет отрезок к фильтру, повторный щелчок снимает его выделение. Можно одновременно выбрать несколько отрезков; таблица покажет объединение их записей. Для пауз соседние граничные удары исключаются. Сбросить выбранные отрезки можно кнопкой временного фильтра или крестиком рядом с временной шкалой.

Порог паузы меняется в поле с иконкой секундомера справа от шкалы или через **Настройки → Пауза между боями…**. Новое значение сразу перестраивает шкалу и сбрасывает выбор её отрезков. Чтобы снять выделение строк таблицы и вернуться к статистике по всей текущей выборке, нажмите `Esc`. Краткая инструкция доступна в меню **Справка** и по клавише `F1`.

## Работа с фильтрами

Фильтры лежат в `src/filter_plugins`. При старте приложение загружает все `*.py` из этой папки и строит по ним чекбоксы в интерфейсе.

Чтобы добавить новый фильтр:

1. Создайте новый файл в `src/filter_plugins` или измените существующий.
2. Добавьте описание фильтра в список `FILTERS`.
3. Перезапустите приложение.

Формат фильтр-плагинов описан в [src/filter_plugins/README.md](src/filter_plugins/README.md).

## Редактирование интерфейса

Исходный файл интерфейса:

```text
src/gui/ui/main_window.ui
```

Редактировать его удобнее через Qt Designer. На Windows он обычно находится в виртуальном окружении:

```text
.venv\Lib\site-packages\PySide6\designer.exe
```

После изменения `.ui` скомпилируйте Python-файл интерфейса:

```powershell
cd tools
python compile_ui.py
cd ..
```

Скомпилированный файл попадет в:

```text
src/gui/compiled_ui/ui_main_window.py
```

## Сборка exe

```powershell
pyinstaller main.spec
```

Готовый исполняемый файл будет создан в `dist`.
