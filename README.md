# DamageViewer

**Разбор урона игроков и духов в Revelation Online.**

Сохраните историю чата в игре и откройте полученный HTML-файл в DamageViewer. Программа покажет, кто и чем атаковал, сколько урона нанёс и какие эффекты действовали. Фильтры, временная шкала и статистика помогут разобраться в деталях боя.

## Когда пригодится

- **Сравнить снаряжение.** Посмотрите, как изменился урон после смены экипировки: обычные удары, криты, средний и максимальный урон.
- **Оценить духов и танка.** Узнайте, сколько урона наносят духи и какие атаки получает танк в Башне затмения.
- **Разобрать гибель в PvP.** Найдите последние атаки перед гибелью на арене или поле боя.
- **Подобрать характеристики.** Посмотрите, как часто противник уклоняется, сколько атак блокируется и как часто проходят криты.

Для сравнения урона бейте одну и ту же цель теми же умениями и с одинаковыми бафами.

## Начало работы

1. Сохраните историю чата в Revelation Online — игра создаст HTML-файл.
2. В DamageViewer выберите **Файл → Открыть логи…** Можно открыть сразу несколько файлов: программа объединит их, убрав дубли из пересекающихся логов.
3. Введите свой никнейм, настройте фильтры слева и выберите нужный бой на шкале над таблицей.

Чтобы быстро открывать свежий лог, укажите папку игры в **Настройки → Выбрать папку с игрой…** Программа будет искать файлы `chat_*.html` в подпапке `game/chat`.

**Открыть логи** и **Загрузить последний лог** заменяют текущие данные. **Добавить последний лог** дополняет их новыми записями.

## Разбор боя

### Фильтры

Оставьте нужного атакующего, цель или умение. Задайте диапазон урона, включите атаки игроков или духов, криты, блокирования, уклонения и эффекты. Группы фильтров можно включать и выключать целиком.

Папка игры, никнейм, текстовые фильтры, диапазон урона и выбранные группы сохраняются между запусками.

### Время

Шкала над таблицей показывает бои и паузы между ними. Нажмите на отрезок, чтобы посмотреть его записи; нажмите ещё раз, чтобы снять выбор. Можно выбрать несколько отрезков сразу. При выборе паузы удары соседних боёв в неё не попадают.

Под шкалой находятся:

- **От / До** — ручной выбор времени;
- **крестик** — сброс выбранных отрезков и временного диапазона;
- **секундомер** — настройка паузы между боями.

По умолчанию новый бой начинается после паузы между ударами **больше 30 секунд**. Порог можно менять от 1 до 3600 секунд — здесь или в **Настройки → Пауза между боями…** Значение сохраняется, шкала обновляется сразу, выбор отрезков сбрасывается.

Наложение и снятие эффектов не продлевает бой. При объединении логов файлы без общих записей разделяются на отдельные бои даже при короткой паузе.

### Статистика

В сводке — число атак, общий урон, минимум, максимум, среднее и медиана. Для критов, блокирований и уклонений показаны количество и процент от числа атак.

Статистика считается по строкам, оставшимся после фильтрации. Выделите несколько строк, чтобы увидеть сводку только по ним. Нажмите `Esc`, чтобы снять выделение.

## Горячие клавиши

| Клавиши | Действие |
| --- | --- |
| `Ctrl+O` | Открыть один или несколько логов |
| `F5` | Загрузить последний лог |
| `Shift+F5` | Добавить последний лог к открытым |
| `Esc` | Снять выделение строк |
| `F1` | Открыть краткую инструкцию |

## Запуск из исходников

Нужны Windows и Python 3.10+. Выполните в папке проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python src/main.pyw
```

## Разработка

Приложение написано на Python и PySide6.

### Свои фильтры

Добавьте определение в список `FILTERS` в одном из файлов `src/filter_plugins` и перезапустите программу. Можно создать отдельный `.py`-файл для своих фильтров.

Формат и примеры — в [руководстве по фильтрам](src/filter_plugins/README.md).

### Интерфейс

Редактируйте `src/gui/ui/main_window.ui` в Qt Designer. В виртуальном окружении он обычно находится в `.venv\Lib\site-packages\PySide6\designer.exe`.

После изменений пересоберите код интерфейса:

```powershell
cd tools
python compile_ui.py
cd ..
```

Результат — `src/gui/compiled_ui/ui_main_window.py`. Этот файл создаётся автоматически; вручную его менять не нужно.

### Сборка для Windows

В активированном окружении выполните:

```powershell
pyinstaller main.spec
```

Готовый exe появится в папке `dist`.

### Структура проекта

```text
src/main.pyw         — запуск приложения
src/core/            — загрузка логов, парсер, настройки и действия
src/gui/windows/     — логика окон
src/gui/widgets/     — виджеты, включая временную шкалу
src/gui/ui/          — формы Qt Designer
src/gui/compiled_ui/  — сгенерированный код форм
src/filter_plugins/  — фильтры
src/resources/       — иконка, шрифты и перевод Qt
tools/compile_ui.py   — сборка кода интерфейса
```
